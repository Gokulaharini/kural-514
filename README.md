# திருக்குறள் 514 – தேர்வு மட்டும் போதுமா?

**Thirukkural 514 – Observe Actions, Not Just Appearances**  
*குழந்தைகளுக்கான ஊடாடும் காட்சி வழிக் கதைப் புத்தகம்*

---

## 📜 1. திருக்குறள் (FIRST — முதலாவதாகத் தோன்றும் குறள்)

> **எனைவகையான் தேறியக் கண்ணும் வினைவகையான்**  
> **வேறாகும் மாந்தர் பலர்.**

*(பொருட்பால் · அதிகாரம்: தெரிந்து வினையாடல் · குறள் 514)*

---

## 💡 2. குறளின் பொருள் விளக்கம் (Meaning)

> ஒருவரை பல வழிகளில் ஆராய்ந்து தகுதியானவர் என்று நாம் தேர்ந்தெடுத்தாலும், அவர் ஒரு பொறுப்பைச் செய்யும்போது அவருடைய செயல்பாடு மாறுபடலாம். எனவே ஒருவரைத் தேர்ந்தெடுத்துவிட்டோம் என்பதோடு முடித்துவிடாமல், அவர் உண்மையில் எப்படிச் செயல்படுகிறார் என்பதையும் தொடர்ந்து கவனிக்க வேண்டும்.

### குழந்தைகளுக்கான எளிய பாடம் (Takeaway):
# **“தேர்வு மட்டும் போதாது; செயலையும் கவனிக்க வேண்டும்.”**

## 🎬 3. காட்சி வழிக் கதை அமைப்பு (Visual Story Flow)

எந்தவொரு ஆடியோ அல்லது நீண்ட பத்திகளும் இன்றி, குழந்தைகள் **அசைவூட்டக் காட்சிகளைப் பார்த்தும் ஊடாடும் பொத்தான்களைத் தொட்டும்** தாங்களாகவே குறளின் பொருளை உணரும் வகையில் இத்திட்டம் வடிவமைக்கப்பட்டுள்ளது:

1. **காட்சி 1: திருக்குறள் 514 (Kural First):**
   - மரப்பலகை ஏட்டுச் சுவடி அமைப்பில் பொன்வண்ண ஒளியுடன் திருக்குறள் முதன்மையாகத் தோன்றுகிறது.
   - குறளுக்கு அருகில் பாரம்பரிய வெண்தாடி, எளிய ஆடை மற்றும் ஓலைச்சுவடி ஏந்திய செல்லமான திருவள்ளுவர் பொம்மை உருவம் (Cute Chibi Thiruvalluvar) இன்லைன் SVG வடிவில் அமைந்துள்ளது.
   - வரிகள் மிகத் துல்லியமாக 4 சொற்கள் முதல் வரியிலும், 3 சொற்கள் இரண்டாம் வரியிலும் மையப்படுத்தப்பட்டு அழகாகப் பிரிக்கப்பட்டுள்ளன.
   - குறளைப் பார்த்த பிறகு, மென்மையான **“அடுத்து →”** பொத்தான் மூலம் கதை தொடங்கும்.
2. **காட்சி 2: பள்ளி விழா ஏற்பாடு (The Event Preparation):**
   - பள்ளி ஆண்டு விழாவுக்காகத் தோரணங்கள், மேடை, பெட்டிகள் (📦), நாற்காலிகள் (🪑), ஒலிபெருக்கி (🎤), திட்டப் பலகை (📋) ஆகியவற்றோடு மாணவர்கள் குழுவாகக் கூடுகிறார்கள்.
3. **காட்சி 3: யாரைத் தேர்ந்தெடுப்பது? (Evaluation & Selection):**
   - மாணவர்கள் நம்பிக்கையுடன் முன்வருகிறார்கள் (*“நான் நன்றாக செய்வேன்!”*, *“என்னை நம்பலாம்!”*, *“பொறுப்பாக பார்த்துக் கொள்கிறேன்!”*).
   - ஆசிரியர் பூதக்கண்ணாடி (🔍) வழியே கவனித்துத் தேர்ந்தெடுக்கிறார் (**✓ தேர்வு**).
4. **காட்சி 4: பொறுப்புகள் வழங்குதல் (Assigning Real Responsibilities):**
   - 📦 **பொருட்களைப் பார்த்துக்கொள்வது** (Materials)
   - 🎨 **மேடையை அலங்கரிப்பது** (Decoration)
   - 🎤 **நிகழ்ச்சிக்குத் தயாராவது** (Stage Coordination)
   - 🪑 **இருக்கைகளை ஏற்பாடு செய்வது** (Seating Arrangement)
   *(விளையாட்டு அல்லது திறமைப் போட்டிகள் போன்ற தொடர்பு இல்லாத கூறுகள் முழுமையாக நீக்கப்பட்டுள்ளன).*
5. **காட்சி 5: உண்மையான செயல்பாடு (The Real Work):**
   - **கவின்:** 📦 → 🏃 → 📦 → ✅ (பொறுப்பைச் சரியாகச் செய்து முடித்தார்)
   - **மலர்:** 🎨 → 👀 → 📱 → 😄 → ⚠️ (வேலையை விட்டுவிட்டு மொபைலில் கவனமாகிவிட்டார்)
   - **அன்பு:** 🎤 → 📋 → 😕 → ⚠️ (பொறுப்பு தொடங்கியதும் குழம்பிப் பணியை முடிக்கவில்லை)
   - **காட்சி உணர்த்தும் உண்மை:** ஆரம்பத் தேர்வின் தோற்றம் உண்மைச் செயல்பாட்டிற்கு உத்தரவாதம் அல்ல!
6. **காட்சி 6: கவனிப்பு படிநிலைகள் (Observation Flow):**
   - 5 படிநிலைக் காட்சி விளக்கம்:
     ```text
     👀 பார்த்தோம் ➔ 🔍 ஆராய்ந்தோம் ➔ ⭐ தேர்ந்தெடுத்தோம் ➔ 📋 பொறுப்பு கொடுத்தோம் ➔ 🎯 செயலையும் பார்த்தோம்
     ```
7. **காட்சி 7: ஊடாடும் கேள்வி & முடிவு (Interactive Question & Conclusion):**
   - ஊடாடும் கேள்வி:
     # **“ஒருவரை தேர்ந்தெடுத்தால் மட்டும் போதுமா?”**
   - **[ ஆம் ]** பொத்தானைத் தொட்டால்: *"🤔 வேலை செய்யும்போது சிலர் வேறு விஷயத்தில் கவனம் செலுத்தினார்கள் அல்லவா? மீண்டும் யோசியுங்கள்!"* என்ற வழிகாட்டுதல் தோன்றும்.
   - **[ இல்லை ]** பொத்தானைத் தொட்டால்:
     # **“இல்லை! செயலையும் கவனிக்க வேண்டும்.”**
     என்ற உண்மை சுடரும் அசைவூட்டத்துடன் வெளிப்படும்.
   - **முதலில் பார்த்தபோது vs வேலை செய்யும்போது** 3D அட்டைத் திருப்புதல்.
   - **↺ மீண்டும் குறளைப் பார்க்க** பொத்தான் மூலம் முதல் காட்சிக்குத் திரும்பும் வசதி.

## 🛠 4. தொழில்நுட்பங்கள் (Technology)

- **HTML5:** Semantic Elements & Accessible Dialogues
- **CSS3:** Responsive Flexbox/Grid, 3D Transforms (`perspective`, `rotateY`), Traditional Wood Plaque, Keyframes
- **Vanilla JavaScript (ES6+):** தூய ஜாவாஸ்கிரிப்ட் ஊடாடல் மற்றும் காட்சி நிலைக் கட்டுப்பாடு (Zero dependencies, Zero frameworks)
- **Inline SVG:** கார்ட்டூன் கதாபாத்திரங்கள் மற்றும் அலங்காரப் பொருட்கள்
